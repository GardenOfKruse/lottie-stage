# Sample Lottie Files

These three animations are bundled so you can try the demo immediately by
dropping them onto the stage.

## Files

| File | Display name | Source | License |
| --- | --- | --- | --- |
| `cat-playing.json` | 橘猫小拾 (Cat) | [LottieFiles](https://www.lottiefiles.com/) | Free for Personal Use |
| `doggie-walk.json` | 柴犬小步 (Shiba) | [LottieFiles](https://www.lottiefiles.com/) | Free for Personal Use |
| `totoro-walk.json` | 龙猫小步 (Totoro) | [LottieFiles](https://www.lottiefiles.com/) | Free for Personal Use |

These are the same files used by the companion-feature preset in the
[timeshards](https://github.com/) project's pet module. They are included
here for demo purposes only.

## Replacing the samples

You can delete any file in this directory and replace it with your own
`.json`. Drag the new file onto the stage in the app, and IndexedDB
will store it for next time.
